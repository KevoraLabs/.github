## 📦 快速安装 (Homebrew)

你可以使用官方 Homebrew Tap 一键安装和更新所有 KevoraLabs 的 macOS 应用：

```bash
# 添加官方 Tap 源
brew tap KevoraLabs/tap

# 安装 KeyLaunch（键启）
brew install --cask KevoraLabs/tap/key-launch

# 安装 PauseLoop（护眼助手）
brew install --cask KevoraLabs/tap/pause-loop
```
